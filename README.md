# nhk-news-op

[Japanese](README_ja.md)

A small web demo that recreates the opening vibe of NHK News.  
This project is a fan-made parody for fun and experimentation and is not affiliated with or endorsed by NHK.

## Demo
- A browser-playable fake NHK design.
- Intended as a lightweight demo to reproduce the look and feel of a news opener.

## Features
- Simple HTML/CSS/JavaScript implementation
- Combined 3D and CSS elements to mimic an opening sequence
- Lightweight and easy to customize for learning or prototyping

## Requirements
- A modern web browser (Chrome, Firefox, Edge, Safari, etc.)
- (Optional for development) Node.js and npm

## Installation / Run (example)
1. Clone the repository:
   ```bash
   git clone https://github.com/ams-design/nhk-news-op.git
   ```
2. Change into the project directory:
   ```bash
   cd nhk-news-op
   ```
4. Start a local server (or simply open `index.html` in your browser)
5. Open your browser at http://localhost:3000 (or the URL shown by your local server)

## Customization
- Edit text, colors, 3D objects, and sound in the source files to change the feel.
